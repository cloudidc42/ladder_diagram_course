## Step 1867: Interview Preparation สำหรับงานในไทย

### สิ่งที่บริษัทไทยมักถาม

```
TECHNICAL QUESTIONS ที่พบบ่อย:

1. PLC Basics:
   Q: อธิบาย Scan Cycle ของ PLC
   A: Input Scan → Program Execution → Output Scan
      ระยะเวลา 1-50ms ขึ้นกับ Program Size

2. Programming:
   Q: ความแตกต่างระหว่าง NO และ NC Contact
   A: NO (Normal Open): เปิดอยู่ปกติ, ปิดเมื่อ Coil ON
      NC (Normal Close): ปิดอยู่ปกติ, เปิดเมื่อ Coil ON

3. Troubleshooting:
   Q: มอเตอร์ไม่หมุน จะตรวจสอบอย่างไร?
   A: Step by Step - ไฟฟ้า (Voltage, Fuse) → PLC Output → Wiring → 
      Motor Protection → Motor

4. Networking:
   Q: PROFINET vs Modbus TCP ต่างกันอย่างไร?
   A: PROFINET: Real-time (<1ms), IRT สำหรับ Motion
      Modbus TCP: Simple, เหมาะกับ Slow Devices

5. Safety:
   Q: Safety PLC vs Standard PLC ต่างกันอย่างไร?
   A: Safety PLC: Redundant CPU, Self-test, Certified PLe/SIL2-3

BEHAVIORAL QUESTIONS:
- เล่าถึงปัญหาที่ยากที่สุดที่เคย Troubleshoot
- งานที่ภูมิใจที่สุด
- ทำงานกับทีมข้ามแผนกอย่างไร
- แผนการพัฒนาตัวเอง 5 ปีข้างหน้า
```
